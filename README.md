# NiMARE Task Classification

A simple logistic-regression baseline for classifying neuroimaging tasks from
coordinate-based modeled activation maps. It compares TruncatedSVD-256 with
DiFuMo-256.

## Run

Tested with Python 3.12.13. With Git installed and a Python environment activated,
run these commands from the repository root:

```bash
python -m pip install -r requirements.txt
python run_svd_difumo_holdout.py
```

The first run downloads the DiFuMo atlas into `atlas_cache/`. This cache is
excluded from Git. NiMARE and pyarrow are pinned; other dependency versions are
not fully locked.

## Data

The prepared dataset is included in `neurostore-studyset-nightly-ml/`, derived
from `neurostore-studyset-nightly.tar.gz`. Task names were normalized and grouped;
multi-task studies and task classes with fewer than 100 studies were removed.
The dataset contains 15 task classes, 2,967 studies, and 11,005 analyses before
coordinate filtering. Provenance, filtering details, and table hashes are
recorded in `studyset.json` inside the dataset folder.

## Experiment

- MKDA modeled activation maps with a 10 mm kernel; labels from
  `metadata.comparison_task`. Analyses without coordinates are dropped.
- Stratified 90%/10% train/test split by study. Analyses from the same study stay in the same split.
- TruncatedSVD with 256 components or DiFuMo with 256 maps at 2 mm resolution,
  followed by StandardScaler and logistic regression (`class_weight="balanced"`,
  `max_iter=1000`).

## Results

Analysis-level precision, recall, support, and overall accuracy are printed in
the terminal. Row-normalized confusion matrices are saved as PNGs in `results/`;
rerunning overwrites files with the same names.

`TruncatedSVD-50_confusion_matrix.png` is from an earlier experiment and is not
generated by the current script.
